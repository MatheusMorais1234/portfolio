Como o código é montado

O Pix copia e cola segue o padrão BR Code do Banco Central: uma sequência de campos em que cada um tem um identificador de dois dígitos, o tamanho do conteúdo e o conteúdo. 5913Fulano de Tal, por exemplo, é o campo 59 (nome do recebedor) com 13 caracteres.

A chave, a mensagem e o identificador vão agrupados no campo 26, que não pode passar de 99 caracteres. Por isso a mensagem é encurtada quando a chave é longa. Nome e cidade têm limite de 25 e 15 caracteres, e acentos são removidos para nenhum aplicativo de banco recusar o código.

Os últimos quatro caracteres são um CRC16, calculado sobre todo o resto. Se qualquer letra for alterada, o banco recusa o código. É esse cálculo que a aba de leitura refaz para dizer se o código está íntegro.

Este gerador cria Pix estático, que pode ser pago mais de uma vez. Pix dinâmico, com vencimento e baixa automática, precisa de integração com a API do banco.
